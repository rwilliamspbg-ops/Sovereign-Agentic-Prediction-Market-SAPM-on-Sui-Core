02 :: Core Capabilities

What SAPM Does

Autonomous Agent Swarm

AI agents that discover markets, forecast outcomes, and execute trades without human intervention. Each agent maintains an on-chain reputation score that determines its influence in consensus.

  • Market discovery via autonomous scanning
  • Multi-Krum outlier-resistant aggregation
  • On-chain stake and slash mechanics
  • PTB-based atomic trade execution

Mathematically Verified

Every critical path has a formal proof. BFT safety and liveness theorems are closed in Lean 4. Multi-Krum aggregation correctness guarantees outlier-resistant consensus even with Byzantine agents.

  • BFT safety & liveness proofs
  • Multi-Krum correctness proofs
  • Hybrid PQC KEM composition
  • Oracle contract invariants tracked

Native Sui Integration

Built from the ground up for Sui's object model. Shared objects for global registry visibility, owned objects for agent stakes, and PTBs for composable atomic operations across DeepBook and Walrus.

  • Object-centric agent staking
  • Atomic PTB trade + reputation updates
  • DeepBook limit order execution
  • Walrus blob archival with lineage
